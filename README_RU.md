# Tarkastus — Android-прототип v0.3

Приложение для создания строительных отчётов на финском языке.

## Что реализовано в текущем коде

- Форма `Yleinen tarkastusraportti` с данными объекта, адресом, заказчиком, подрядчиком, проверяющим и описанием проверки.
- Карточки дефектов с местом, описанием и рекомендуемым действием.
- Несколько фотографий на каждый дефект и комментарий к каждой фотографии.
- Разметка фото: свободное рисование, стрелки, круги, прямоугольники и текст.
- Сохранение оригинала фотографии отдельно от размеченной версии.
- Выбор логотипа и подпись пальцем.
- Локальный черновик и архив отчётов.
- Создание PDF и системное меню Android для отправки/сохранения PDF.

## Сборка APK

В репозитории настроен GitHub Actions workflow:
`.github/workflows/build.yml`

1. Открой вкладку **Actions** репозитория.
2. Выбери **Build Tarkastus APK**.
3. Если запуск доступен, нажми **Run workflow** и подтверди ветку `main`.
4. Открой завершившийся запуск и скачай Artifact **Tarkastus-debug-apk**.
5. Внутри ZIP-архива будет `app-debug.apk`.

Workflow использует JDK 21, Gradle 8.13, Android Gradle Plugin 8.13.0 и Android SDK 36. Gradle Wrapper в репозитории не требуется: Gradle устанавливается непосредственно в workflow.

## Ограничения и проверка

- APK ещё не подтверждён успешной сборкой и не протестирован на реальном устройстве.
- Черновики, архив и изображения хранятся локально в приватной памяти приложения. Перед удалением приложения экспортируй нужные PDF.
- Пока нет встроенной съёмки камерой, облачной синхронизации и конструктора шаблонов.
- Перед рабочим использованием нужно проверить PDF с длинными текстами и большим количеством фотографий, восстановление архива и работу на HONOR Magic V3.
