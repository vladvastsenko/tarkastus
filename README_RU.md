# Tarkastus — Android-проект (прототип v0.3)

Исходный проект приложения для создания универсальных строительных отчётов на финском языке.

## Реализовано в коде
- Универсальная форма `Yleinen tarkastusraportti`.
- Поля объекта, адреса, заказчика, подрядчика, проверяющего и описания проверки.
- Неограниченное количество карточек дефектов в рамках доступной памяти телефона.
- Несколько фотографий для каждого дефекта (выбор нескольких изображений из системного файлового окна).
- Отдельный комментарий к каждой фотографии.
- Разметка фотографии: свободное рисование, стрелки, круги, прямоугольники и текстовые отметки.
- Сохранение оригинала фотографии отдельно от размеченной версии.
- Общий логотип, поле подписи пальцем.
- Локальное сохранение черновика.
- Архив независимых отчётов, открытие ранее сохранённых отчётов и создание нового отчёта.
- Генерация PDF с логотипом, дефектами, фотографиями, комментариями и подписью.
- Системное меню Android для отправки/сохранения PDF.

## Сборка APK через GitHub Actions
1. Создать новый репозиторий на GitHub.
2. Загрузить в него содержимое этой папки `Tarkastus` (не сам ZIP-файл).
3. Открыть вкладку **Actions**.
4. Запустить workflow **Build Tarkastus APK** (или отправить commit в ветку `main`).
5. После успешной сборки открыть запуск workflow и скачать Artifact `Tarkastus-debug-apk`.
6. Внутри артефакта находится `app-debug.apk`; установить его на Android.

Проект использует Android Gradle Plugin 8.13.0, Gradle 8.13, JDK 21 и Android SDK 36.

## Важные ограничения прототипа
- Код обновлён, но APK в этой среде не собран и не прошёл тестирование на реальном устройстве.
- Архив и фотографии хранятся локально в приватной памяти приложения. Удаление приложения может удалить эти данные — PDF следует регулярно сохранять отдельно.
- Пока нет встроенной съёмки камерой, синхронизации с облаком и полноценного конструктора шаблонов.
- Перед рабочим использованием необходимо проверить сборку, PDF-перенос длинных текстов, восстановление архива и работу на HONOR Magic V3.
